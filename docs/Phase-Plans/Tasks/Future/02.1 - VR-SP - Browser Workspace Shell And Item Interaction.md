## Working Read

Current locked direction from the family docs:
- `[2.1]` should turn the Browser from an honest tree into an honest workspace shell
- every Browser row should follow one shared anatomy:
  - `[Expand] [Type Icon] [Name / Label] [State] [Controls]`
- the row is the control surface
- controls should stay:
  - small
  - right-aligned
  - secondary to the hierarchy
- Browser single-click should create lightweight Browser selection
- graph-row click may request presentation-only viewer emphasis for that graph's currently resolved published outputs
- Browser click must not silently:
  - open/focus an editor viewport
  - retarget shared composition
  - change shared-composition membership
  - mutate ownership truth
- explicit open/focus actions still own editor movement
- richer Browser workspace systems now carry forward beyond the shipped `2.1A` and `2.1B` cuts
- the roadmap split is now:
  - `[2.1A]`
    - Browser workspace shell and row interaction
  - `[2.1B]`
    - Browser/editor/shared-viewer coordination
  - likely later `[2.1C]`
    - Browser row-action cleanup, context-menu-first commands, and Browser/shell honesty cleanup
