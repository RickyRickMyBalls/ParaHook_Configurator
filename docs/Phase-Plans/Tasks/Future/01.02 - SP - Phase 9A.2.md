## Arch Spec

### Spec Target

This implementation target is only:
- `[1.1A.2] SP - Phase 9A.2 - Graph-Owned Authored Canvas State`

This cut is intentionally narrow:
- move only per-node row mode
- keep it graph-owned
- do not absorb full collapse-state migration

If this cut is wrong, later work has no stable base for:
- `9A.3` viewport binding
- `9B` multi-editor Browser behavior
- `GE 11` save/load of authored canvas truth

So this cut should stay phase-pure and small.

### Problem Statement

After `9A.1`, graph identity is explicit, but authored canvas state is still split incorrectly.

Current runtime truth:
- node positions are already graph-owned in `SpaghettiGraph.ui.nodes`
- per-node row mode still lives in `useSpaghettiUiStore.nodeModeByNodeId`
- `NodeView` reads node mode directly from `useSpaghettiUiStore`
- `SpaghettiCanvas` writes node mode through `useSpaghettiUiStore`

At the same time, several other canvas states are still intentionally local:
- section/group/composite collapse state in `useSpaghettiUiStore`
- composite expansion in local `SpaghettiCanvas` React state
- details expansion in local `NodeView` React state

`9A.2` needs to move only the authored part of that seam.

### Current Execution Rules

Code-grounded rules for this cut:

- `SpaghettiGraph` already has a graph-owned `ui` seam:
  - `ui.nodes`
  - `ui.viewport`
- `9A.2` should extend that same seam rather than creating a new top-level authored-canvas object
- `SpaghettiCanvas` remains a heavy seam file, so this cut should change the smallest number of ownership paths necessary
- if a state is about temporary reading, expansion, or inspection, it stays local in this phase

### Seams To Break In 9A.2

This cut only needs to break these seams:

1. `nodeModeByNodeId` cannot remain `useSpaghettiUiStore` truth
2. `NodeView` cannot read node mode from `useSpaghettiUiStore`
3. `SpaghettiCanvas` cannot mutate node mode through `useSpaghettiUiStore`
4. section/group/composite collapse state stays local for now and is intentionally not part of this cut

Follow-on note:
- viewport identity and focused-window behavior belong to `9A.3` and `9B`, not this cut

### Canonical `9A.2` State Contract

Base this phase on the real current schema seam in `SpaghettiGraph.ui`.

Lock this first-pass contract:

```ts
type ViewMode = 'collapsed' | 'essentials' | 'expanded'

type SpaghettiGraph['ui'] = {
  nodes?: Record<string, GraphNodePos>
  nodeModesByNodeId?: Record<string, ViewMode>
  viewport?: {
    x: number
    y: number
    zoom: number
  }
}
```

Rules:
- `ui.nodes` stays the graph-owned home of node positions
- `ui.nodeModesByNodeId` becomes the graph-owned home of per-node row mode
- `essentials` is the default mode
- default `essentials` entries should be omitted from stored state to keep the record sparse
- `ui.viewport` is not part of `9A.2` authored-canvas work and must not be expanded in this phase
