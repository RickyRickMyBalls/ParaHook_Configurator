### Summary

`5.0D` is the catch-all cleanup cut for everything that is still left in after the real `5.0A-C` work lands.

This phase exists so ParaHook can:
- remove dead shell residue without pretending it blocks `[5.1]`

Important rule:
- `5.0D` is deferred cleanup
- it should not hold up the main `[5.1] Workspace Modes` lane unless one of these leftovers turns out to be a direct blocker

- remove the title-bar `Build Stats` drawer behavior from `TitleStatusBar` / `BuildStatsDrawer`

- any surviving viewer concepts such as `parts` versus `assembled` are either:
