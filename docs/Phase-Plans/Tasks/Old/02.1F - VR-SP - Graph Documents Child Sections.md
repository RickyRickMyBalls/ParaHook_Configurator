## Locked Implementation

### Spec Target

This implementation target was only:
- `[2.1F] VR / SP - Graph Documents Child Sections`

Plain-English rule:
- replace the old raw graph publish-entry child list with one graph-side work section and one graph-side inventory section

### Shipped Child-Section Shape

Each graph document row now expands into:
- `Needs Rebuild`
- `Nodes`

Order and defaults:
- `Needs Rebuild` is first and default-open
- `Nodes` is second and default-closed
- after first render, section expand/collapse state is remembered per graph row

### Shipped `Needs Rebuild` Rules

`Needs Rebuild` rows now:
- represent graph-owned published object rows, not raw slot/output-entry rows
- follow published `Content` order
- include unresolved produced objects
- exclude empty/non-producing rows such as `s002`
- exclude already-clean rows
- disappear once rebuilt and clean

### Shipped `Nodes` Rules

`Nodes` rows now:
- represent all graph nodes
- stay flat, not grouped
- follow graph node order

### Shipped Click Behavior

Single-click on both graph child row types now:
- focuses or opens the same graph if needed
- selects the source node
- acts as graph-authoring reveal

This is intentionally not:
- a `Content` rebuild action
- a project-content selection/highlight action
