## Purpose

This file is the short master wishlist for future features.

Use it as:
- a quick scan of major desired features
- a top-level index of the bigger wish-feature docs
- a place to see what kinds of ideas are still in the "future feature" bucket

This is not the phase roadmap and not the task backlog.
It is the broad feature wish list.

## Master Wishlist

- [ ] Spaghetti editor window upgrade
  - toolbar / half-screen / full-screen / browser-window modes
- [ ] Spaghetti editor toolbar redesign
  - cleaner layout, smaller info area, canvas controls merged into the toolbar
- [ ] Wires UI overhaul
  - cleaner routing, validation visibility, active render-path behavior
- [ ] Node-system cleanup and growth
  - better node organization, clearer node families, cleaner spawn palette
- [ ] Driver system expansion
  - stronger param/input/driver contracts and equation-ready growth
- [ ] Jake mode
  - simplified end-user editing layer over the canonical model
- [ ] Control-viz spheres
  - plane-constrained handles and richer driver bindings
- [ ] Multi-graph Spaghetti editor
  - multiple loaded graphs, graph-aware parts, graph-aware preview/debug
- [ ] Multi-window Spaghetti editor
  - floating and browser-window editor hosts
- [ ] Graphs panel
  - graph-aware replacement/expansion of the flat parts list
- [ ] Feature Stack growth
  - more features beyond `sketch` and `extrude`
- [ ] Part hardening
  - Baseplate, ToeHook, HeelKick, presets, metadata, stronger production behavior
- [ ] OutputPreview / assembly growth
  - part transforms, assembly relationships, richer inspection
- [ ] Debug system expansion
  - graph, node, feature, resolver, and wiring inspection
- [ ] Gizmo parity return
  - old top-right gizmo look and controls
- [ ] Scenes return
  - stars, nebula, swarm, and their controls
- [ ] Radio / sampler return
  - the old audio/radio interaction ideas in a cleaner form
- [ ] Old viewer/workbench feature return
  - section cut, reference workspace, richer materials/layers controls
- [ ] Shared viewport composition
  - multiple graphs and multiple outputs in one viewer
- [ ] Export growth
  - STL, STEP, profile export, manufacturing metadata
- [ ] Spaghetti Studio / Parametric Parts direction
  - future platform growth beyond ParaHook
